# 🎬 Netflix Recommendation System

A content-based movie & TV show recommender over the **8,790-title Netflix
catalogue**, built with **TF-IDF + cosine similarity** and served as an
interactive web demo (GitHub Pages) and a **Streamlit** app you can run
locally. Pick any title and instantly get the most
similar titles, each with a match score, type, year, rating, genres and
director/country details.

**Live Demo:** [mabdulrafay7zip.github.io/Netflix-Recommender-Live-Demo](https://mabdulrafay7zip.github.io/Netflix-Recommender-Live-Demo/) — runs entirely in your browser from precomputed recommendations (`recs.json`); no sign-up and no server to wait for.

## How it works

1. Every title is turned into one short **text profile** built from its
   genres (`listed_in`), country, director, type and rating (multi-word
   names are squashed into single tokens, e.g. `MikeFlanagan`).
2. **TF-IDF** (`TfidfVectorizer`, English stop-words removed) vectorises all
   8,787 unique-title profiles — a vocabulary of ~5,400 terms.
3. **Cosine similarity** between the selected title's vector and the whole
   catalogue ranks the recommendations; the model is built once and cached.

No user ratings or history are needed — pure content-based filtering.

> **Why two catalogue numbers?** `data.csv` contains 8,790 rows, but 3 titles
> are duplicated. `load_catalogue()` in `app.py` drops duplicates (keeping the
> first entry), so the model works with 8,787 unique titles — the count the
> test suite asserts in `tests/test_recommender.py`.

## Project context

This app is the live-demo version of an end-to-end ML project,
first built as a standalone Python script (`recommendation_system.py`).
The wider project set — content-type prediction (91.9% accuracy), rating
classification and K-Means content segmentation — lives in the
[Netflix_ML_Projects](https://github.com/mabdulrafay7zip/Netflix_ML_Projects) repository.

## Run it locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL Streamlit prints (default http://localhost:8501).

## Tests

The core logic in `app.py` is covered by a pytest suite in `tests/`
(catalogue loading, recommendations excluding the query title, and
match scores sorted between 0 and 100):

```bash
pip install pytest
pytest -q
```

## Files

| File | Purpose |
|------|---------|
| `app.py` | Streamlit app + the TF-IDF recommender (cached data/model) |
| `index.html` | GitHub Pages demo page — looks up precomputed recommendations in the browser |
| `recs.json` | Precomputed recommendations for every title, generated by the TF-IDF model |
| `data.csv` | Trimmed Netflix catalogue (8,790 rows: title, type, director, country, release year, rating, duration, genres) |
| `requirements.txt` | streamlit, pandas, scikit-learn |
| `tests/test_recommender.py` | Pytest suite for catalogue loading and `recommend()` behaviour |
